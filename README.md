## ✨ About The Project

**AMJ Enterprises** is a modern business website developed for an LED wall rental and professional visual solutions company.

The website provides a digital presence where potential customers can explore the company's services, view visual installations and portfolio work, understand the business, and quickly access enquiry/contact options.

The project focuses on combining a strong visual identity with practical business functionality.

### Main development goals

- Create a professional online presence for AMJ Enterprises
- Present LED wall and visual services clearly
- Showcase completed installations and visual work
- Provide an attractive experience for event customers
- Support desktop, tablet and mobile devices
- Make enquiries and contact information easy to access
- Maintain a clean and modern frontend architecture
